== NAME

soptools - 用于项目构建的 SOP 工作流引导工具

== SYNOPSIS

*soptools* [_OPTION_]... [_PROJECTDIR_]

== DESCRIPTION

*soptools* loads a Standard Operating Procedure (SOP) directory and guides the user step-by-step through project construction tasks. Each step may be a shell script, an AI output capture, or a manual checkpoint.

SOP files use the naming convention:

____
....
<seq><variant>.<_padded_role>.<title>.md
....
____

The GUI shows a workflow graph, branch selection, forward/back navigation, automated run controls, and optional logging. Console mode provides a text interface with the same workflow engine.

== OPTIONS

*-s, --suite* _NAME_

____
SOP suite under *suite/* (default: *worldman*). Branch (*default* / *zh_CN* / *ja*) follows *LANG* / *LC_ALL* / *LC_MESSAGES* unless *--sop-dir* is set.
____

*-S, --sop-dir* _DIR_

____
Explicit SOP directory (overrides *--suite* and LANG). WorldMan branches live at *suite/worldman/{default,zh_CN,ja}/*.
____

*-c, --console*

____
Use console-only mode without a GUI.
____

*-g, --gui*

____
Force GUI mode even when no display is detected.
____

*-C, --chdir* _DIR_

____
Project directory. By default *soptools* walks upward from the current working directory looking for *.git*; if none is found, the current directory is used.
____

*-v, --verbose*

____
Increase logging verbosity. Repeat for more detail.
____

*-q, --quiet*

____
Reduce logging output.
____

*-h, --help*

____
Print a usage summary and exit successfully.
____

*--version*

____
Print version and license information and exit successfully.
____
