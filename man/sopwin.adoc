== Name

sopwin - guided SOP workflow assistant for project construction

== Synopsis

*sopwin* [_OPTION_]... [_CMD_=open] [_ARGS_]...

== Description

*sopwin* loads a Standard Operating Procedure (SOP) directory and guides the
user step-by-step through project construction tasks. Each step may be a shell
script, an AI output capture, or a manual checkpoint.

Commands:

*open* [_PROJECTDIR_]::
  Show the main window and open the project (default).

*run* _PROJECTDIR_::
  Run the SOP in console mode.

*copydlg*::
  Standalone clipboard helper used as the default chat/code agent UI
  (*--paste* or *--confirm*).

*edit* _SOPDIR_::
  Open the SOP authoring editor for a suite directory.

*version*::
  Print version and license information.

SOP files use the naming convention:

[source]
----
<seq><variant>.<_padded_role>.<title>.(md|sh|get)
----

Roles: *shell*, *chat*, *code* (legacy *gpt* / *codex* accepted).
Variant *a* is the default branch choice; *z* is optional/alternative.
Markdown steps may declare YAML frontmatter `extend: previous` or
`extend: next` to merge into an adjacent step of the same type (role +
extension); the graph shows one concatenated node.
Bodies may use `\response` (nearest prior chat output) and `<select>` /
`<option>` blocks (resolved with a dialog before the step runs).
Project file *sop/AGENTS* maps roles to agent cmdlines (default: *sopwin
copydlg* for chat/code).
The builtin SOP suite is *worldman* under *suite/worldman/* (*default* / *zh_CN* / *ja*).

The GUI shows a workflow graph, branch selection, forward/back navigation,
automated run controls, and optional logging. Console mode provides a text
interface with the same workflow engine.

== Options

*-s, --suite* _NAME_::
  SOP suite under *suite/* (default: *worldman*). Branch (*default* /
  *zh_CN* / *ja*) comes from *LANG* / *LC_ALL* / *LC_MESSAGES* unless
  *--sop-dir* is set.

*-S, --sop-dir* _DIR_::
  Explicit SOP directory (overrides *--suite* and LANG branch). WorldMan
  branches: *suite/worldman/{default,zh_CN,ja}/*.

*-c, --console*::
  Use console-only mode without a GUI.

*-g, --gui*::
  Force GUI mode even when no display is detected.

*-C, --chdir* _DIR_::
  Project directory. By default *sopwin* walks upward from the current working
  directory looking for *.git*; if none is found, the current directory is used.

*-v, --verbose*::
  Increase logging verbosity. Repeat for more detail.

*-q, --quiet*::
  Reduce logging output.

*-h, --help*::
  Print a usage summary and exit successfully.

*--version*::
  Print version and license information and exit successfully.

== Exit status

*0*::
  Success.

*1*::
  An error occurred.
