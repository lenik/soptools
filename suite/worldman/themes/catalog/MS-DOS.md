# MS-DOS

group: vibe

## Meaning / 含义

Microsoft DOS — classic 1980s–90s PC text mode. Nostalgic terminal energy; not designed for minimal eye strain.

Microsoft DOS——1980–90 年代经典 PC 文本模式。怀旧终端气质；并非为低视疲劳而设计。
