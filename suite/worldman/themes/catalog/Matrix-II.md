# Matrix-II

group: vibe

## Meaning / 含义

Reference to The Matrix (1999) — neon green on near-black; cyberpunk terminal best in a dim room.

向《黑客帝国》（1999）致敬——近黑底上的霓虹绿；赛博终端，宜暗室。

## Matrix II

### English

Neon green (~h 135°) on green-tinted near-black panels. Subtle grid/border greens; cursor and active elements glow. Dark-only.

### 中文

霓虹绿（约 h135°）落在偏绿近黑面板上。网格/边框微绿；光标与激活态发光。仅深色。
