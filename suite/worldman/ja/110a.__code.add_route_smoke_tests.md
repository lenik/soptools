# Playwright ルートスモークテストを追加する

`web-e2e/` 配下に Playwright E2E テストを追加する。

まずルートスモークカバレッジを実装する。

アプリのルート表を列挙する。

到達可能な各アプリルートについて：

- ルートを開く
- ページが描画されることを確認する
- クラッシュしないことを確認する
- 致命的なページエラーがないことを確認する
- 予期しない未捕捉例外がないことを確認する
- ページが空白でないことを確認する

動的ルートは有効なシードデータ ID を使うか、必要なテストデータを作成する。

ルートスモークテストを十分な機能カバレッジとみなさない。
