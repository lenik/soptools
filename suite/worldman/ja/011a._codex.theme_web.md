# Web UI をテーマ化する（WorldMan styleclass）

プロジェクトのテーマ添付 `sop/themes/` を使い、`web/` にセマンティックな
テーマを適用する。手順 `010` の構造リファクタとは分ける。

`sop/themes/` が無い場合は、先にスイートの `suite/worldman/themes/`
（言語ブランチの兄弟）からコピーする。

プロジェクト時点で minor-themes アーカイブに**依存しない**。ソース構成は
`ELEMENTS.md` / `SCHEMA.md` 参照：

```text
sop/themes/
  catalog/          # 色彩言語の散文（Yesterday.md、X-Files.md、…）
  minor/            # soft / pride — ui|token|web|erp-palettes.mjs
  vibe/             # メディア / レトロ
  country/          # 国の文化パレット
  catalog.tsv
```

## 固定の主 styleclass 名

WorldMan Web アプリは次の主 styleclass / CSS 変数語幹を**必ず**使う：

| styleclass | 役割 |
|------------|------|
| `background` | アプリ／ページのキャンバス |
| `foreground` | 既定の本文 |
| `primary` | ブランド／主アクション |
| `primary-foreground` | primary 上の文字／アイコン |
| `card` | 浮いた面 |
| `card-foreground` | カード上の文字 |
| `accent` | 選択／柔らかいハイライト |
| `accent-foreground` | accent 上の文字 |
| `muted-foreground` | 副次／ヒント文字 |
| `border` | 枠線／区切り |
| `ring` | フォーカスリング |
| `destructive` | 危険／削除 |
| `success` | 成功ステータス |
| `warning` | 警告ステータス |

`:root`（必要なら `.dark`）に `--${name}` として書き、フレームワークへ橋渡し。
共有コントロールはこれらのトークンを消費する。ハードコード色を上記役割へ移行。

## 意味に応じて全 class セットを使う

WorldMan の **web** リファクタは `webPalettes` に**限定しない**。実 UI の意味に合う
セットを選ぶ：

| ソース | `web/` での用途 |
|--------|----------------|
| `web-palettes.mjs` | アプリクロム、ページ、ボタン、状態（既定の製品 UI） |
| `ui-palettes.mjs` | 密なツール／IDE 風クロム（パネル、タブ、サイドバー） |
| `erp-palettes.mjs` | 一覧、フォーム、金額、ワークフロー状態 |
| `token-palettes.mjs` | コード／式／ハイライト面 |

1. `sop/themes/catalog.tsv` で id → `group` + `paletteKey` + catalog md。
2. 必要に応じ `sop/themes/<group>/{web,ui,erp,token}-palettes.mjs` を import。
3. `catalog/<Family>.md` を美的ブリーフとして残す。
4. 共有コンポーネントは上記の固定 **web** 主名を優先；他セットは
   `--ui-*` / `--erp-*` / `--tok-*` 接頭辞で衝突を避ける。

4 シーンのプレビュー: ローカル静的サーバで `sop/themes/index.html` を開く。

色は主に `hsl(...)`。意味的前景／背景は ≥ 4.5:1。国パレットは **zfr L2 + L3**
（Tier I–III）をカバー（`catalog.tsv` / `ELEMENTS.md`）。

## 副次／中間色

並行命名を作らない。欠けた副次トークンは主色から明度／彩度を調整して生成してよい
（`muted`、`secondary`、`popover`、`sidebar*`、`app-canvas` など）。

## 適用とスイッチャー

1. `applyTheme(id)`／任意 `previewTheme(id)`（CSS 変数、`.dark`、`localStorage`、
   可能なら初回描画前）。
2. クロムに**見える**テーマ操作を置き、`minor` / `vibe` / `country` でグループ化。
3. 既定: 明るい soft（例: `innocent`）か Figma に近いもの。

レイアウトと操作は維持し、色だけをトークン経由で変える。
