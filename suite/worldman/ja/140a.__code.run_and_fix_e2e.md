# E2E テストの実行と修復

完全な Playwright テストスイートを実行する。

失敗について：

1. 失敗が次のどれかを判断する：
   - 製品実装バグ
   - バックエンドバグ
   - 統合バグ
   - テストバグ
   - 不安定なセレクタ
   - 誤ったテストデータ仮定

2. 正しい層を直す。

通すためだけにテストを弱めない。

ワークフローが確立された製品仕様と矛盾しない限り、意図ワークフローを変えない。

定義されたすべてのワークフローが動くまで繰り返す。

## SOP 駆動コミット

本手順が**進むにつれて**コミットする——まとまったスライスのあと（成果物の書き出し、
1ルート／機能の抽出、1モック置換、一部テストが green、…）。
手順全体を末尾の単一コミットに**先送りしない**。

SOP 駆動の件名は `[sop140]` で始めなければならない。本 SOP パックの
`CHECKPOINT.md` を参照。
