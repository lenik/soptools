# 运行并修复 E2E 测试

运行完整 Playwright 测试套件。

对失败：

1. 判断失败属于：
   - 产品实现缺陷
   - 后端缺陷
   - 集成缺陷
   - 测试缺陷
   - 不稳定选择器
   - 错误的测试数据假设

2. 修复正确的层。

不要仅为通过而削弱测试。

除非工作流与既定产品规格矛盾，否则不要改变预期工作流。

重复直至所有已定义工作流都能工作。

## SOP 驱动的提交

**随本步骤演进**提交——在每个连贯切片之后（写出产物、
抽出一条路由/功能、替换一个 mock、子集测试转绿，…）。
**不要**把整个步骤拖到步骤末尾一次提交。

SOP 驱动的主题必须以 `[sop140]` 开头。见本 SOP 包中的
`CHECKPOINT.md`。
