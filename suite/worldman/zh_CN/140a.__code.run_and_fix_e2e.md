# 运行并修复 E2E 测试

运行完整的 Playwright 测试套件。

对失败：

1. 判定失败属于：
   - 产品实现缺陷
   - 后端缺陷
   - 集成缺陷
   - 测试缺陷
   - 不稳定选择器
   - 错误的测试数据假定

2. 在正确的一层修复。

不要仅为让测试通过而削弱测试。

除非工作流与既定产品规格矛盾，否则不要改预期工作流。

重复直到所有已定义工作流都能工作。

## SOP 驱动的提交

**随本步骤演进**提交——每完成一块连贯切片（产物已写出、某条路由/功能已抽出、某个 mock 已替换、某子集测试已绿等）。**不要**把整步工作拖到步骤末尾一次提交。

SOP 驱动的主题必须以 `[sop140]` 开头。见本 SOP 包中的 `CHECKPOINT.md`。
