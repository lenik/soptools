# 主题化 Web UI（WorldMan styleclass）

使用项目主题附件 `sop/themes/` 对 `web/` 做语义主题化。本步骤与 `010` 的结构
重构分开。

若缺少 `sop/themes/`，先从套件包 `suite/worldman/themes/`（语言分支同级）复制。

**不要**在项目构建时依赖 minor-themes 仓库。源文件分组如下（见 `ELEMENTS.md` /
`SCHEMA.md`）：

```text
sop/themes/
  catalog/          # 色彩语言散文（Yesterday.md、X-Files.md、…）
  minor/            # 柔和 / pride — ui|token|web|erp-palettes.mjs
  vibe/             # 影剧 / 复古
  country/          # 国家文化色板
  catalog.tsv
```

## 固定的主 styleclass 名称

WorldMan Web 应用**必须**使用下列主 styleclass / CSS 变量词干：

| styleclass | 角色 |
|------------|------|
| `background` | 应用 / 页面画布 |
| `foreground` | 默认正文 |
| `primary` | 品牌 / 主操作 |
| `primary-foreground` | 主色上的文字/图标 |
| `card` | 浮起表面 |
| `card-foreground` | 卡片上的文字 |
| `accent` | 选中 / 柔和高亮 |
| `accent-foreground` | accent 上的文字 |
| `muted-foreground` | 次要 / 提示文字 |
| `border` | 边框 / 分隔 |
| `ring` | 焦点环 |
| `destructive` | 危险 / 删除 |
| `success` | 正向状态 |
| `warning` | 警告状态 |

在 `:root`（及需要时的 `.dark`）上写为 `--${name}`，并桥接到 CSS 框架。
共享控件必须消费这些 token。将硬编码颜色迁到上述角色。

## 按语义加载全部 class 集

WorldMan **web** 重构**不限于** `webPalettes`。按真实界面语义选用：

| 来源 | 在 `web/` 中的用途 |
|------|-------------------|
| `web-palettes.mjs` | 应用铬、页面、按钮、状态（默认产品 UI） |
| `ui-palettes.mjs` | 密工具 / IDE 式铬（面板、标签、侧栏） |
| `erp-palettes.mjs` | 列表、表单、金额、流程状态 |
| `token-palettes.mjs` | 代码 / 公式 / 高亮表面 |

1. 读 `sop/themes/catalog.tsv`：id → `group` + `paletteKey` + catalog md。
2. 按需导入 `sop/themes/<group>/{web,ui,erp,token}-palettes.mjs`。
3. 保留 `catalog/<Family>.md` 作为美学简报。
4. 共享组件优先用上文固定的 **web** 主名；其它集合用前缀变量
   （`--ui-*`、`--erp-*`、`--tok-*`）避免冲突。

四场景预览：本地静态服务打开 `sop/themes/index.html`。

色值多为 `hsl(...)`。语义前景/背景对比度 ≥ 4.5:1（打包时检测）。国家色板覆盖
**zfr L2 + L3**（Tier I–III），见 `catalog.tsv` / `ELEMENTS.md`。

## 次要 / 中间色

**不要**另起并行命名。未给出的次要 token 可在集成时按主色调整明度/饱和度生成
（如 `muted`、`secondary`、`popover`、`sidebar*`、`app-canvas` 等）。

## 应用与切换器

1. 实现 `applyTheme(id)` / 可选 `previewTheme(id)`（写 CSS 变量、`.dark`、
   `localStorage`，尽量首屏前调用）。
2. 在应用铬架加入**可见**主题控件，按 `minor` / `vibe` / `country` 分组。
3. 默认：浅色 soft（如 `innocent`）或最接近 Figma 的主题。

保持布局与交互；仅通过 token 换色。
