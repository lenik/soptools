# 主题化 Web UI（WorldMan styleclass）

使用项目主题 fork `sop/themes/` 对 `web/` 做语义主题化。本步骤衔接 `010`
（`extend: previous`）。

`sop/themes/` 是套件附件 `suite/worldman/themes/` 的**项目本地副本**（由
`000` 播种）。可按本产品演进——增删色板、调 HSL、裁剪国家包——项目构建时
**不要**依赖上游 minor-themes 仓库。

若缺少 `sop/themes/`，先从套件包复制（含 `scripts/`）：

```text
sop/themes/
  catalog/          # 色彩语言散文
  minor|vibe|country/  ui|token|web|erp-palettes.mjs
  scripts/generate-theme-css.mjs   # 可二开的 CSS 生成脚本
  catalog.tsv
  ELEMENTS.md / SCHEMA.md
```

## 建议的主 styleclass 名称

WorldMan Web 应用**建议**使用下列主 styleclass / CSS 变量词干，以便共享模块
一致。优先桥接工具类（`bg-background`、`text-primary` 等）。项目可按需扩展或
改名；故意偏离时记入 `sop/TODO.md`。

| styleclass | 角色 |
|------------|------|
| `background` | 应用 / 页面画布 |
| `foreground` | 默认正文 |
| `primary` | 品牌 / 主操作 |
| `primary-foreground` | 主色上的文字/图标 |
| `card` | 浮起表面 |
| `card-foreground` | 卡片上的文字 |
| `accent` | 选中 / 柔和高亮 |
| `accent-foreground` | accent 上的文字 |
| `muted-foreground` | 次要 / 提示文字 |
| `border` | 边框 / 分隔 |
| `ring` | 焦点环 |
| `destructive` | 危险 / 删除 |
| `success` | 正向状态 |
| `warning` | 警告状态 |

在 `:root`（及需要时的 `.dark`）上写为 `--${name}`，并桥接到 CSS 框架。
共享控件尽量消费这些 token。将硬编码颜色迁到上述角色。

## 从 `sop/themes/` 生成 CSS（必要）

**不要**在应用 CSS 里手抄维护与色板重复的 HSL。用附带脚本从 fork 生成样式表
（可在 `sop/themes/scripts/` 下二开）：

```bash
# 在项目根目录
node sop/themes/scripts/generate-theme-css.mjs
# 默认输出：web/src/styles/themes/themes.css（及 themes-web.css 等）
node sop/themes/scripts/generate-theme-css.mjs --out web/src/styles/themes --sets web,ui
```

在 `web/` 中导入生成结果，用 `data-theme="<id>"` 切换（见 catalog.tsv）。
改色板后重新跑生成脚本。

## 按语义加载全部 class 集

WorldMan **web** 主题化**不限于** `webPalettes`。按真实界面语义选用
（生成器 `--sets`）：

| 来源 | 在 `web/` 中的用途 |
|------|-------------------|
| `web-palettes.mjs` | 应用铬、页面、按钮、状态（默认产品 UI） |
| `ui-palettes.mjs` | 密工具 / IDE 式铬（面板、标签、侧栏） |
| `erp-palettes.mjs` | 列表、表单、金额、流程状态 |
| `token-palettes.mjs` | 代码 / 公式 / 高亮表面 |

1. 读 `sop/themes/catalog.tsv`：id → `group` + `paletteKey` + catalog md。
2. 优先用 `scripts/generate-theme-css.mjs` 生成 CSS，避免浏览器运行时直接
   import `.mjs`。
3. 保留 `catalog/<Family>.md` 作为美学简报。
4. 共享组件优先用上文**建议的** web 主名；其它集合用前缀变量
   （`--ui-*`、`--erp-*`、`--tok-*`）避免冲突。

四场景预览：本地静态服务打开 `sop/themes/index.html`。

语义前景/背景对比度 ≥ 4.5:1（套件打包时检测）。国家色板覆盖 **zfr L2 + L3**。

## 次要 / 中间色

**不要**另起并行命名。未给出的次要 token 可按主色调整明度/饱和度生成
（如 `muted`、`secondary`、`popover`、`sidebar*`、`app-canvas` 等）。若项目
需要中间色合成，扩展 `generate-theme-css.mjs`。

## 保留当前配色为默认

接入主题时，**尽量保持项目现有 Figma / CSS 配色为默认**。先把线上颜色映射到
WorldMan styleclass token（`default` / `current` 包，或与导出一致的启动值）。

**不要**因为上了主题体系就静默换成库存的 `innocent`（或其它包）。`minor` /
`vibe` / `country` 下的库存包是**可选切换项**；首屏应仍像当前产品。

## 应用与切换器

1. 实现 `applyTheme(id)` / 可选 `previewTheme(id)`：
   - 设置 `document.documentElement.dataset.theme = id`（对应生成 CSS）
   - `type === "dark"` 时切换 `.dark`
   - `localStorage` 持久化；尽量首屏前调用
2. 在应用铬架加入**可见**主题控件，按 `minor` / `vibe` / `country` 分组。
3. 默认 = **当前产品配色**（见上）。若故意用库存包作默认，记入 `sop/TODO.md`。

保持布局与交互；仅通过 token 换色。
