检查：

- PRD 功能无实现
- 设计清单中标为 `kept`/`moved` 的路由/页签相对 Figma 基线缺失、空白或被掏空
- 设计清单 **Typography** 字族被换成其它字体或主题色板字体
- 文档 `<title>` / Vite `figma:title` 仍是 `Figma Make App`（须为
  `{族} | {代码} | {标题}`）
- 启动主题不是 `default`（从 Figma 提取），或现成色板被静默当成产品默认（`011` 跑过时见 `sop/theme-default.md`）
- seed 覆盖缺口仍让用户可见列表/表格为空
- 非 `matched` 行缺少 seed 覆盖 **差异记录**，或 media↔text `mismatched` 却无理由
- TUC / NTC / ECS 用例无后端或 E2E 覆盖
- 本应关闭却仍打开的 `sop/TODO.md` 项
- 已实现领域功能缺失于文档
- 无真实行为的 UI 控件
- 死按钮
- 死菜单
- 死路由
- 在 seed 对等**之后**本应已替换的过时 mock 数据
- 过时的本地持久化
- 无后端测试的 API 端点
- 重要后端功能无 E2E 路径
- 无 Playwright 覆盖的工作流步骤
- 无覆盖的交互控件
- 过时的 API 文档
- 本应由后端处理却从未处理的 schema 字段
- 与后端行为不一致的前端假定
- 改写了多处表面却无中间 `[sopNNN]` 提交的 SOP 工作（记在 `sop/TODO.md`；不要改写已发布历史）
- 共享库里残留的 E2E/API **测试污染**（测试创建却从未删除的行）
- Figma 字族仍热链，或因 Google Fonts 不可达就换字体，却未尝试代理 + `$HOME/.cache/fonts`

修复真实缺口——优先恢复清单支持的 UI/seed 数据（以及 Figma `default` 主题 / 字体栈），而不是删掉该面或“改样式”来让审计“通过”。

若 API 有意超出当前 web 应用复用，不要强迫每个后端 API 能力都有 GUI。

最后运行：

- 后端测试
- web build/typecheck
- Playwright E2E 测试

所有必需测试必须通过。
