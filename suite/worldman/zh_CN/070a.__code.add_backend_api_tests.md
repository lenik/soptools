# 添加后端 API 测试

添加自动化后端 API 测试。

测试应覆盖实际公共 API 行为，而不是内部实现细节。

在适用处覆盖：

- 创建
- 读取
- 更新
- 删除/归档
- 列表
- 搜索
- 过滤
- 排序
- 分页
- 查找
- 关系
- 树操作
- 状态转换
- 校验失败
- 未找到
- 冲突
- 防重复
- 批量操作
- 历史/版本行为
- 领域特定操作

同时测试从以下材料发现的重要边界情况：

- `sop/PRD.md`
- `sop/TUC.md`（若存在）
- `sop/NTC.md`（若存在）
- `sop/ECS.md`（若存在）
- `prisma/schema.prisma`
- `prisma/seed.ts`

当用户提示或实现工作暴露新用例时，及时更新 `sop/TUC.md`、`sop/NTC.md`、`sop/ECS.md`。
测试应使用确定性测试数据。

运行后端测试。

修复后端实现与测试，直至后端测试套件通过。

在将前端集成问题当作前端问题之前，后端测试必须先通过。
