# 添加 Playwright 路由冒烟测试

在 `web-e2e/` 下添加 Playwright E2E 测试。

首先实现路由冒烟覆盖。

从路由器**以及** `sop/design-inventory.md` 枚举应用路由表。每个状态为 `kept` 或 `moved`
的清单路由都必须有冒烟测试，除非清单以理由标为 `dropped`。

对每条可达应用路由：

- 打开该路由
- 验证页面渲染
- 验证不崩溃
- 验证无致命页面错误
- 验证无意外未捕获异常
- 验证页面非空白
- 当清单在该路由上列出页签时，抽查这些页签仍能挂载
  （点击或深链），而不是静默消失

动态路由应使用有效 seed 数据 ID，或创建所需测试数据。

不要把路由冒烟测试视为足够的功能覆盖。

## SOP 驱动的提交

**随本步骤演进**提交——在每个连贯切片之后（写出产物、
抽出一条路由/功能、替换一个 mock、子集测试转绿，…）。
**不要**把整个步骤拖到步骤末尾一次提交。

SOP 驱动的主题必须以 `[sop110]` 开头。见本 SOP 包中的
`CHECKPOINT.md`。
