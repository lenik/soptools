# 添加 Playwright 路由冒烟测试

在 `web-e2e/` 下添加 Playwright E2E 测试。

先实现路由冒烟覆盖。

从路由器**以及** `sop/design-inventory.md` 枚举应用路由表。清单中状态为 `kept` 或 `moved` 的每条路由都必须有冒烟测试，除非清单已标 `dropped` 并写明理由。

对每条可到达的应用路由：

- 打开该路由
- 验证页面能渲染
- 验证不崩溃
- 验证无致命页面错误
- 验证无意外未捕获异常
- 验证页面不是空白
- 若清单在该路由下列有页签，抽查这些页签仍能挂载（点击或深链），而不是静默消失

动态路由应使用有效的 seed 数据 ID，或创建所需测试数据。

若冒烟/工作流辅助逻辑会**创建** API/DB 行，须在同一测试（或共享 fixture 的 `afterAll`）里拆卸，以免污染共享库。优先用 seed ID，不要创建后忘记删除。

不要把路由冒烟测试当作足够的功能覆盖。

## SOP 驱动的提交

**随本步骤演进**提交——每完成一块连贯切片（产物已写出、某条路由/功能已抽出、某个 mock 已替换、某子集测试已绿等）。**不要**把整步工作拖到步骤末尾一次提交。

SOP 驱动的主题必须以 `[sop110]` 开头。见本 SOP 包中的 `CHECKPOINT.md`。
