# 撰写最终 API 文档

后端实现与集成稳定后，写出完整的 `docs/api.md`。

本文档描述实际已实现的 API。

它是建成态 API 合同。

文档化：

- API 基路径
- 通用约定
- 适用处的认证
- 请求格式
- 响应格式
- 错误格式
- 分页
- 筛选
- 排序
- 搜索
- 批量操作约定
- 资源端点
- 状态迁移端点
- 关系端点
- 领域专用端点
- 示例
- 重要校验规则
- 重要冲突行为

对每个端点，提供足够信息，使另一应用无需阅读后端源码即可使用该 API。

不要文档化不存在的端点。

不要只因当前 web 应用未调用，就省略已实现的有用端点。
