# 为 web UI 做主题（WorldMan styleclass）

使用项目主题 fork `sop/themes/`，为 `web/` 应用语义化主题。

本步骤声明 `extend: previous`。当它被纳入 SOP 路径时，
**sopwin 将其并入 `010` 成为图上的单一步骤**（提示词正文
拼接；仅显示 `010` 节点）。不要去掉 `extend` 去强制独立
节点——WorldMan 保持稳定的步骤数；可选主题是这种合并扩展，
而不是额外的 seq。

`sop/themes/` 是 suite 附件
`suite/worldman/themes/` 的**项目本地 fork**（由步骤 `000` 播种）。为本产品演进它——
增删色板、调整 HSL、裁剪国家包——而不在项目时依赖上游
minor-themes 归档。

若缺少 `sop/themes/`，先从 suite 包拷贝（含
`scripts/`）。布局：

```text
sop/themes/
  catalog/          # color-language prose
  minor|vibe|country/  ui|token|web|erp-palettes.mjs
  scripts/generate-theme-css.mjs   # forkable CSS generator
  catalog.tsv
  ELEMENTS.md / SCHEMA.md
```

## 推荐的主 styleclass 名称

WorldMan web 应用**推荐**使用这些主 styleclass /
CSS 变量词干，以便共享模块保持一致。偏好从它们桥接的工具类
（`bg-background`、`text-primary` 等）。项目可按需扩展或重命名——
在 `sop/TODO.md` 中记录有意偏离。

| styleclass | 职责 |
|------------|------|
| `background` | 应用 / 页面画布 |
| `foreground` | 默认正文文字 |
| `primary` | 品牌 / 主操作 |
| `primary-foreground` | 主色上的文字/图标 |
| `card` | 抬升表面 |
| `card-foreground` | 卡片上的文字 |
| `accent` | 选中 / 柔和高亮 |
| `accent-foreground` | accent 上的文字 |
| `muted-foreground` | 次要 / 提示文字 |
| `border` | 边框 / 分隔 |
| `ring` | 焦点环 |
| `destructive` | 危险 / 删除 |
| `success` | 积极状态 |
| `warning` | 警示状态 |

在 `:root`（以及需要时的 `.dark`）上以 `--${name}` 接线，并经
CSS 框架桥接（如 Tailwind `@theme`）。共享控件在可行时应消费
这些 token。

把硬编码颜色（`bg-blue-500`、`text-gray-900`、`bg-[#007AFF]` 等）
迁移到这些角色。仅在照片/地图/画布对比真正需要时保留稀有字面颜色。

## 从 `sop/themes/` 生成 CSS（必需）

**不要**手工维护与色板 HSL 重复的应用主题 CSS。用随附脚本
从 fork 生成样式表（随项目演进在
`sop/themes/scripts/` 下定制）：

```bash
# from project root
node sop/themes/scripts/generate-theme-css.mjs
# default out: web/src/styles/themes/themes.css (+ themes-web.css, …)
node sop/themes/scripts/generate-theme-css.mjs --out web/src/styles/themes --sets web,ui
```

在 `web/` 中导入生成的 CSS，并用 `data-theme="<id>"` 驱动切换
（见 catalog.tsv）。色板编辑后重新运行生成器。

## 加载色板 — 按语义使用全部 class set

WorldMan **web** 主题**不**限于 `webPalettes`。使用与真实 UI 含义匹配的
任意 class set（生成器 `--sets`）：

| 来源 | 在 `web/` 中何时使用 |
|------|----------------------|
| `web-palettes.mjs` | 应用 chrome、页面、按钮、状态（默认产品 UI） |
| `ui-palettes.mjs` | 稠密工具 / IDE 式 chrome（面板、页签、侧栏） |
| `erp-palettes.mjs` | 列表、表单、金额、工作流状态 |
| `token-palettes.mjs` | 代码 / 公式 / 高亮表面 |

1. 读 `sop/themes/catalog.tsv` 获取 id → `group` + `paletteKey` + catalog md。
2. 偏好经 `scripts/generate-theme-css.mjs` 生成 CSS，而非在浏览器运行时
   导入 `.mjs`。
3. 将 `catalog/<Family>.md` 作为美学简报保留。
4. 共享组件偏好上文推荐的 **web** 主名；
   其它 set 映射到带清晰前缀的 CSS 变量（`--ui-*`、`--erp-*`、
   `--tok-*`）以免冲突。

预览场景：经本地静态服务器打开 `sop/themes/index.html`。

语义 fg/bg 对在 suite 包中做过对比度检查（≥ 4.5:1）
（`tools/check-theme-contrast.mjs`）。国家包覆盖 **zfr L2 + L3**。

## 次级 / 中间调

**不要**发明第二套命名方案。省略时可选次级 token 可由
**生成**得到——从主色调整明度/饱和度
（与 minor-themes 中间调同工艺精神，但面向 web 角色），例如 `muted`、
`secondary`、`popover`、`input-background`、`sidebar*`、`app-canvas`，以及
状态 `*-foreground` 对。若项目需要中间调合成，扩展
`generate-theme-css.mjs`。

## 把当前外观保留为 `default`（硬性契约）

主题存在是为了**把颜色映射到 token，并可选用切换**——不是为了重样式
Figma 产品。代理常因把库存包（`innocent`、某个国家包等）装成首屏，
或因换字体而失败。防止这些：

1. **提取**活的 Figma / 导出 CSS 颜色，写入字面名为
   `default` 的主题 id（仅当你也注册了 `default` 时才可用别名 `current`）。
   映射到推荐的 styleclass token（`background`、
   `foreground`、`primary` 等）。取值必须匹配导出——构建 `default` 时不要
   “改善”对比度、色相或渐变。
2. **首屏 / 启动**必须使用 `default`，除非 `localStorage` 已持有
   来自先前会话的**用户**选择。绝不要因为生成列表把某个库存包排在前面
   就启动到该包。
3. `minor` / `vibe` / `country` 下的库存包仅为**可选切换器
   选项**。生成它们的 CSS 可以；把其中任一设为产品默认则不可以。若你有意
   交付非 Figma 默认，须在 `sop/TODO.md` 中用明确产品理由记录（少见）。
4. **字体排印不在主题范围内。** 不要为了匹配某个包的简报而更改
   `font-family`、字重、字号阶梯、字距或行高。
   保留清单的 Typography 小节；仅把带颜色的属性改写到 token 上。
5. 写出 `sop/theme-default.md`，记录 `default` 包：
   - token → 提取值（有用时含源文件/选择器）
   - 字体栈保持不变
   - 确认启动使用 `data-theme="default"`（或等价物）

## 应用 + 切换器

1. 实现 `applyTheme(id)` / 可选 `previewTheme(id)`：
   - 设置 `document.documentElement.dataset.theme = id`（匹配生成的 CSS）
   - 当 `type === "dark"` 时切换 `.dark`
   - **仅在用户显式切换之后**才把 id 持久化到 `localStorage`（不要
     预种库存 id）
   - 在首屏绘制前于启动时调用一次：无用户选择时解析为 `default`
2. 添加主题控件时**不要重设计 Figma chrome**：
   - 若清单中已有，优先复用既有设置 / 溢出 / 页脚控件。
   - 否则使用低调、非英雄式控件（如小菜单项或
     开发者入口）。**不要**发明导出所没有的醒目页头/工具条
     条带、徽章簇或营销式主题选择器。
   - 在该控件内按 `minor` / `vibe` / `country`（或 catalog 族）
     分组可选包。把 `default` 列在最前，并标注为 Figma /
     产品外观。
3. 复核 `sop/design-inventory.md` — 本步骤不得丢弃已列出的
   路由/页签，也不得重样式布局、字体排印、间距或
   导航。仅通过 token 改颜色。
