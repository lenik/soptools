# Add Playwright route smoke tests

Under `web-e2e/`, add Playwright E2E tests.

First implement route smoke coverage.

Enumerate the application's route table from the router **and** from
`sop/design-inventory.md`. Every inventory route with status `kept` or `moved`
must have a smoke test unless the inventory marks it `dropped` with reason.

For every reachable application route:

- open the route
- verify the page renders
- verify it does not crash
- verify there is no fatal page error
- verify there is no unexpected uncaught exception
- verify the page is not blank
- when the inventory lists tabs on that route, spot-check that those tabs still
  mount (click or deep-link) rather than silently vanishing

Dynamic routes should use valid seed-data IDs or create required test data.

When a smoke/workflow helper **creates** API/DB rows, tear them down in the
same test (or shared fixture `afterAll`) so a shared database is not polluted.
Prefer seed IDs over create-then-forget.

Do not consider route smoke tests sufficient functional coverage.
