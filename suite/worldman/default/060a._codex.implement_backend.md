# Implement backend

Paste the backend implementation prompt produced by GPT and implement the backend under `backend/`.

## Prisma package

Inspect the existing `prisma/` directory first. Expect at least:

- `prisma/schema.prisma`
- `prisma/seed.ts` (if already authored)
- `prisma/package.json` (add if missing)
- `prisma/request-for-refactor.md` (optional; from the seed step)

Use this package; do not invent a second Prisma root.

### Merge `request-for-refactor` into the schema

If `prisma/request-for-refactor.md` exists, this step **authorizes** applying its schema changes:

1. Read every issue in `request-for-refactor.md`.
2. Apply **blocking** items to `prisma/schema.prisma` (and related prisma files such as `comments.sql` when needed).
3. Apply **recommended** items when they are small, reversible, and required for a coherent API; otherwise record deferral in the implementation notes.
4. Update `prisma/seed.ts` so it still matches the revised schema.
5. After merging, either remove `request-for-refactor.md` or rewrite it so only unresolved deferred items remain (do not leave applied blocking requests as open work).

Do not skip this merge and build the backend against a schema known to be insufficient.
