# Final coverage audit

Perform a final product coverage audit across:

- `sop/PRD.md`
- `sop/design-inventory.md`
- `sop/seed-coverage.md`
- `sop/TUC.md` (if present)
- `sop/NTC.md` (if present)
- `sop/ECS.md` (if present)
- `sop/TODO.md` (if present)
- `prisma/schema.prisma`
- `prisma/seed.ts`
- `backend/`
- `docs/api.md`
- `web/`
- `web-e2e/workflows.md`
- `web-e2e/`

Check for:

- PRD features without implementation
- design-inventory routes/tabs marked `kept`/`moved` that are missing, blank, or gutted vs the Figma baseline
- design-inventory **Typography** families replaced by a different typeface or theme-pack font
- boot theme not `default` (Figma-extracted), or stock pack silently made the product default (see `sop/theme-default.md` when `011` ran)
- seed-coverage gaps that still empty user-visible lists/tables
- seed-coverage **Discrepancy log** missing for non-`matched` rows, or media↔text `mismatched` without rationale
- TUC / NTC / ECS cases without backend or E2E coverage
- open `sop/TODO.md` items that should have been closed
- implemented domain features missing from documentation
- UI controls with no real behavior
- dead buttons
- dead menus
- dead routes
- obsolete mock data that should already have been replaced **after** seed parity
- obsolete local persistence
- API endpoints without backend tests
- important backend features with no E2E path
- workflow steps without Playwright coverage
- interactive controls without coverage
- stale API documentation
- schema fields never handled by backend where they should be
- frontend assumptions inconsistent with backend behavior
- SOP work that rewrote many surfaces with no intermediate `[sopNNN]` commits (note in `sop/TODO.md`; do not rewrite published history)
- leftover E2E/API **test pollution** in the shared DB (rows created by tests and never deleted)
- Figma font families still hotlinked or replaced because Google Fonts was unreachable without trying proxy + `$HOME/.cache/fonts`

Fix genuine gaps — prefer restoring inventory-backed UI/seed data (and the
Figma `default` theme / font stacks) over deleting the surface or “restyling”
to make audits “pass”.

Do not force every backend API capability to have a GUI if the API is intentionally reusable beyond the current web application.

Finally run:

- backend tests
- web build/typecheck
- Playwright E2E tests

All required tests must pass.
