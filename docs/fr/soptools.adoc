== Name

soptools - guided SOP workflow assistant for project construction

== Synopsis

*soptools* [_OPTION_]... [_PROJECTDIR_]

== Description

*soptools* loads a Standard Operating Procedure (SOP) directory and guides the
user step-by-step through project construction tasks. Each step may be a shell
script, an AI output capture, or a manual checkpoint.

SOP files use the naming convention:

[source]
----
<seq><variant>.<_padded_role>.<title>.md
----

Variant *a* is the default branch choice; *z* is optional/alternative.
The builtin SOP suite is *worldman* under *suite/worldman/* (branches
*default*, *zh_CN*, *ja*) for WorldMan module construction.

The GUI shows a workflow graph, branch selection, forward/back navigation,
automated run controls, and optional logging. Console mode provides a text
interface with the same workflow engine.

== Options

*-s, --suite* _NAME_::
  SOP suite name under *suite/* (default: *worldman*). The suite branch
  (*default* / *zh_CN* / *ja*) is selected from *LANG* / *LC_ALL* /
  *LC_MESSAGES* unless *--sop-dir* is set.

*-S, --sop-dir* _DIR_::
  SOP directory to load (overrides *--suite* and LANG branch selection).
  WorldMan branches live at *suite/worldman/{default,zh_CN,ja}/*.

*-c, --console*::
  Use console-only mode without a GUI.

*-g, --gui*::
  Force GUI mode even when no display is detected.

*-C, --chdir* _DIR_::
  Project directory. By default *soptools* walks upward from the current working
  directory looking for *.git*; if none is found, the current directory is used.

*-v, --verbose*::
  Increase logging verbosity. Repeat for more detail.

*-q, --quiet*::
  Reduce logging output.

*-h, --help*::
  Print a usage summary and exit successfully.

*--version*::
  Print version and license information and exit successfully.

== Exit status

*0*::
  Success.

*1*::
  An error occurred.
