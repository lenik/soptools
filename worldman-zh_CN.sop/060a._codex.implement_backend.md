# 实现后端

粘贴 GPT 产出的后端实现提示词，并在 `backend/` 下实现后端。

## Prisma 包

先检查已有 `prisma/` 目录，至少应有：

- `prisma/schema.prisma`
- `prisma/seed.ts`（若已编写）
- `prisma/package.json`（若缺失则补上）
- `prisma/request-for-refactor.md`（可选；由 seed 步骤产出）

使用该包，不要另起一套 Prisma 根目录。

### 将 `request-for-refactor` 合并进 schema

若存在 `prisma/request-for-refactor.md`，**本步骤授权**将其方案合入 schema：

1. 阅读其中每一项问题。
2. 将 **blocking** 项应用到 `prisma/schema.prisma`（必要时同步 `comments.sql` 等 prisma 相关文件）。
3. 对 **recommended** 项：若改动小、可回退且为一致 API 所必需则一并应用；否则在实现说明中记录延期原因。
4. 更新 `prisma/seed.ts`，使其与修订后的 schema 一致。
5. 合并后删除 `request-for-refactor.md`，或仅保留尚未解决的延期项（不要把已应用的 blocking 请求留成未结工作）。

不得跳过合并、却对着已知不足的 schema 实现后端。
