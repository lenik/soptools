# 编写最终 API 文档

在后端实现与集成稳定后，编写完整 `docs/api.md`。

该文档描述实际已实现的 API。

它是建成后的 API 契约。

文档应覆盖：

- API 基路径
- 通用约定
- 认证（如适用）
- 请求格式
- 响应格式
- 错误格式
- 分页
- 过滤
- 排序
- 搜索
- 批量操作约定
- 资源端点
- 状态转换端点
- 关系端点
- 领域特定端点
- 示例
- 重要校验规则
- 重要冲突行为

每个端点应包含足够信息，使另一应用无需阅读后端源码即可使用 API。

不要文档化不存在的端点。

不要仅因当前 Web 应用未调用就省略有用的已实现端点。
