# Create PRD

根据此前所有讨论和当前产品设计整理完整：

```text
docs/PRD.md
```

要求：

- 用于开发和后续验收，不只是领导汇报材料。
- 以当前已经讨论确认的需求为准。
- 不擅自扩大产品边界。
- 对存在明确业务含义的内容进行补全和规范化。
- 对前面讨论中隐含但已经可以推导出的约束进行明确描述。

PRD 至少覆盖：

```text
Product overview
Goals
Scope
Out of scope
Terminology
User roles
Domain concepts
Core entities
Entity relationships
Business rules
Lifecycle/state transitions
CRUD behavior
Search
Filter
Sort
Pagination where relevant
Bulk operations
Import/export where relevant
Media
History/audit behavior where relevant
External references
Validation rules
Deletion/archive behavior
Empty states
Error behavior
Important edge cases
Main UI workflows
Non-functional expectations
```

对于跨应用引用：

- 明确说明逻辑引用对象。
- 不自动假定数据库外键。
- 使用 `<xxx>_id` 等稳定标识引用其他应用数据时，应在 PRD 中说明其语义。

输出 `PRD.md` 下载链接。
