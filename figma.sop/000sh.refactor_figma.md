# Refactor the Figma project

Run from `project/`.

```bash
rm -rf AGENT.md CLAUDE.md src/imports .figma .git

mkdir -p web

shopt -s dotglob extglob
mv !(web) web

[ -f web/.gitignore ] && mv web/.gitignore .

mkdir -p docs prisma backend web-e2e mobile mobile-e2e

git init
git add .
git commit -m "init"
```

Expected repository layout:

```text
project/
    prisma/
    backend/
    web/
    web-e2e/
    mobile/
    mobile-e2e/
    docs/
    .gitignore
```

Do not move repository-level files back into `web/` after this point.
