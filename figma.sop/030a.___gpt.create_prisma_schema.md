# Create Prisma schema

Create complete Prisma schema for PostgreSQL.

Output:

```text
prisma/schema.prisma
prisma/comments.sql
```

Requirements:

- target PostgreSQL
- use `cuid(2)` for ID columns
- use `snake_case` for database table names
- use `snake_case` for database column names
- include meaningful Prisma documentation comments
- convert relevant Prisma comments into PostgreSQL `COMMENT ON` statements
- use PostgreSQL schema:

```text
<appname>
```

Design requirements:

- model the complete product domain, not merely the currently visible Figma screens
- preserve historical information where the domain requires it
- distinguish lifecycle state from deletion where appropriate
- provide useful indexes for common lookup/search patterns
- add unique constraints only when they represent actual domain rules
- avoid unnecessary database coupling to other applications
- cross-application IDs should normally be scalar cuid2-compatible fields without database foreign-key constraints unless explicitly required
- avoid using JSON when a stable relational structure is clearly known
- use JSON when the structure is genuinely dynamic or extension-oriented

Do not generate `seed.ts` in this step.

Provide download links.
