# バックエンドを実装する

GPT が作成したバックエンド実装プロンプトを貼り付け、`backend/` 配下にバックエンドを実装する。

## Prisma パッケージ

まず既存の `prisma/` ディレクトリを確認する。少なくとも次を想定する：

- `prisma/schema.prisma`
- `prisma/seed.ts`（作成済みなら）
- `prisma/package.json`（無ければ追加）
- `prisma/request-for-refactor.md`（任意。seed 手順の成果物）

このパッケージを使う。別の Prisma ルートを新設しない。

### `request-for-refactor` を schema へマージする

`prisma/request-for-refactor.md` がある場合、**本手順がその schema 変更を許可する**：

1. ファイル内の各 issue を読む。
2. **blocking** 項目を `prisma/schema.prisma` へ適用する（必要なら `comments.sql` など関連ファイルも）。
3. **recommended** は、小さく可逆で一貫した API に必要なものだけ適用し、それ以外は実装ノートに延期理由を残す。
4. 改訂後の schema に合うよう `prisma/seed.ts` を更新する。
5. マージ後は `request-for-refactor.md` を削除するか、未解決の延期項目だけ残す（適用済み blocking を未完了のまま残さない）。

このマージを飛ばして、不足が分かっている schema のままバックエンドを実装しない。
